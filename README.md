# Seventeen Syllables of Debugging

A haiku about debugging — three lines in the 5-7-5 syllable shape — written by a tiny Python program for make.fun's "Seventeen Syllables of Debugging" bounty.

The cursor at 3 a.m., a stack trace that shrugs, and the eternal last-line turn: it was my typo.

## Run

```
python3 main.py
```

Writes the haiku to `/output/entry.txt`.
